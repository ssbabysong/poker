# 牌局本 · 德扑战绩

手机端德州扑克成绩记录与追踪。纯静态 PWA，数据只保存在本机浏览器。

- **记一场**：现金局 / 比赛、日期、地点、级别、买入、带出、时长、名次、备注
- **实时牌局**：开始计时 → 记录加买 → 结束时自动带出买入合计和时长
- **统计**：总盈亏、时薪、胜率、回报率、连胜连败、可按住查看的累计曲线、按月 / 地点 / 级别汇总
- **备份**：复制或粘贴备份、JSON 文件导入导出、CSV 表格导出
- 深色 / 浅色主题，可添加到主屏幕离线使用

## 部署
推送到 `main` 后由 `.github/workflows/pages.yml` 自动发布到 GitHub Pages
（仓库 Settings → Pages → Source 需选 **GitHub Actions**）。
